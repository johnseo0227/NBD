# NBD — 감사 일기

매일 감사한 일을 기록하는 웹앱(PWA)입니다. 아이폰과 윈도우에 앱처럼 설치할 수 있고, 설치 후에는 인터넷 없이도 열립니다. 로그인하면 기기 사이에 기록이 동기화되고, 정한 시각에 알림을 받을 수 있습니다.

**이 앱만의 특징**: 감사를 적는 데서 끝나지 않고, **감사가 사람에게 닿고 다시 나에게 돌아오도록** 설계했습니다.
- 💌 **고마운 사람 노트**: 사람마다 감사한 순간이 모이고, 그 순간들을 묶어 감사 편지로 보낼 수 있습니다.
- 📅 **다시 찾아오는 감사**: 1년 전 오늘, 예전에 별표한 순간이 화면과 알림으로 돌아옵니다. 힘든 날엔 별표한 기억을 먼저 보여 줍니다.
- 📈 **나만의 효과 리포트**: 연구 결과 대신 내 기록으로, 감사 일기를 쓰고 나서 기분이 얼마나 달라지는지 보여 줍니다.

## 기능

- **오늘** (2~3분)
  - 감사한 일을 "무엇이 / 왜"로 1~5개 씁니다. 범주(사람·경험·나·자연·물건·환경), 누구 덕분인지, 내가 한 역할도 적을 수 있습니다.
  - 쓰기 전·후 기분을 기록하고, 나에게 고마운 점을 씁니다. 자동 저장됩니다.
  - "오늘은 힘든 날"을 켜면 힘든 날에 맞는 질문으로 바뀝니다.
  - 예전에 쓴 것과 비슷한 내용을 쓰면 알려 줍니다.
  - 설정에서 아침 질문("오늘을 좋은 날로 만들 한 가지")을 켤 수 있습니다.
  - 위쪽에 1년·6개월·한 달 전 오늘의 기록이나 예전에 별표한 순간이 나타납니다.
  - 저장하면 오늘의 기분 변화와 지금까지의 평균을 알려 줍니다.
- **기록**: 지난 일기를 사람·단어로 검색하고, ⭐한 항목만 모아 봅니다.
- **회고**
  - 주간: ⭐ 고르기 → 하나를 골라 "이게 없었다면?" 깊이 쓰기 → 고마운 사람에게 메시지 보내기(공유 시트) → 한 줄 회고
  - 월간: 쓴 날, 고마운 사람 순위, 감사의 범주 비율, 효과 리포트(이번 달·전체·힘든 날의 기분 변화, 날짜별 그래프), 이 달의 ⭐
- **사람**: "누구 덕분인가요?"에 적은 사람별로 감사한 순간을 모아 봅니다.
  - 세 번 넘게 고마웠는데 한 달 넘게 마음을 전하지 않은 사람에게 "고마움을 전해 볼까요?"가 붙습니다.
  - 순간을 골라 감사 편지를 만들고(편하게/정중하게), 고쳐서 공유 시트로 보냅니다.
- **설정**: 동기화 로그인, 알림, 하루 항목 수, JSON 백업 내보내기/가져오기

## 설치

1. **배포**: 저장소를 공개(public)로 바꾸고 Settings → Pages → Source를 **GitHub Actions**로 선택합니다. 이후 `main`에 올라가는 변경은 `.github/workflows/pages.yml`이 자동으로 배포합니다. 주소는 `https://<사용자명>.github.io/NBD/`입니다.
2. **아이폰**: Safari로 주소 열기 → 공유 버튼 → "홈 화면에 추가"
3. **윈도우**: Edge나 Chrome으로 주소 열기 → 주소창 오른쪽 "앱 설치" 아이콘

## 동기화 설정 (Supabase, 무료)

1. [supabase.com](https://supabase.com)에서 새 프로젝트를 만듭니다.
2. **SQL Editor**에서 [`supabase/schema.sql`](supabase/schema.sql) 내용을 붙여 넣고 실행합니다.
3. **Authentication → URL Configuration**의 Site URL을 배포 주소(`https://<사용자명>.github.io/NBD/`)로 바꿉니다. 가입 확인 메일의 링크가 이 주소로 연결됩니다.
4. **Project Settings → API**에서 Project URL과 anon(또는 publishable) 키를 복사해 [`config.js`](config.js)에 넣습니다. 이 키는 공개되어도 됩니다. 각 사용자는 자기 기록만 읽고 쓸 수 있도록 서버 규칙(RLS)이 막습니다.
   - `config.js`를 고치지 않고 앱의 설정 → "서버 설정"에 직접 넣어도 됩니다(그 기기에만 저장).
5. 앱의 설정 탭에서 회원가입 → 메일 확인 → 로그인합니다. 다른 기기에서는 같은 계정으로 로그인하면 됩니다.

동작 방식:
- 기록은 먼저 기기에 저장되고, 온라인일 때 서버와 주고받습니다. 오프라인에서 쓴 것은 연결되면 올라갑니다.
- 같은 날짜를 두 기기에서 고치면 **나중에 고친 쪽**이 남습니다.
- 로그인하면 그 기기에 이미 있던 기록도 계정에 합쳐집니다. 로그아웃해도 기기의 기록은 지워지지 않습니다.
- 서버에 저장된 일기는 암호화되지 않은 상태로, Supabase 프로젝트 관리자(본인)가 볼 수 있습니다.

## 푸시 알림 설정

아이폰(iOS 16.4 이상)은 **홈 화면에 추가한 앱**에서만 알림을 받을 수 있습니다. 윈도우는 Edge나 Chrome이면 됩니다. 알림은 위의 동기화 설정을 마친 뒤 설정할 수 있습니다.

| 알림 | 기본 시각 | 내용 |
|---|---|---|
| 매일 쓰기 | 21:30 | 연속 기록 일수와 함께. 그날 이미 썼으면 보내지 않음 |
| 일요일 회고 | 20:00 (일요일) | 이번 주 쓴 날과 감사 개수. 회고를 이미 했으면 보내지 않음 |
| 다시 찾아오는 감사 | 08:30 | 1년·6개월·한 달 전 오늘, 또는 예전에 별표한 순간 |

1. **VAPID 키 만들기**: 터미널에서 `npx web-push generate-vapid-keys`를 실행합니다. 공개키(Public Key)와 개인키(Private Key)가 나옵니다.
   - 공개키는 [`config.js`](config.js)의 `vapidPublicKey`에 넣습니다.
   - **개인키는 저장소에 넣지 마세요.** 다음 단계의 비밀값으로만 씁니다.
2. **함수 배포**: Supabase 대시보드 → Edge Functions → "Deploy a new function" → "Via Editor"를 고릅니다.
   - 이름을 `send-reminders`로 하고 [`supabase/functions/send-reminders/index.ts`](supabase/functions/send-reminders/index.ts) 내용을 붙여 넣어 배포합니다.
   - 함수 설정에서 **Verify JWT를 끕니다.** 대신 아래 `CRON_SECRET`으로 확인합니다.
   - CLI를 쓴다면: `npx supabase functions deploy send-reminders --no-verify-jwt --project-ref <project-ref>`
3. **함수 비밀값**: Edge Functions → Secrets에 다음을 추가합니다.
   - `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`: 1번에서 만든 키
   - `VAPID_SUBJECT`: `mailto:내이메일`
   - `CRON_SECRET`: 아무도 추측할 수 없는 긴 임의 문자열
4. **5분마다 실행**: SQL Editor에서 [`supabase/cron.sql`](supabase/cron.sql)의 `<project-ref>`와 `<CRON_SECRET 값>`을 바꿔 실행합니다.
5. 앱의 설정 → 알림에서 원하는 알림과 시각을 고르고 "알림 켜기"를 누릅니다. "테스트 알림"으로 권한이 잘 되었는지 확인할 수 있습니다.

동작 방식:
- 알림 설정은 기기마다 따로 저장됩니다. 아이폰은 아침 알림만, 윈도우는 저녁 알림만 받는 식으로 쓸 수 있습니다.
- 시각은 각 기기의 시간대 기준입니다. 정한 시각부터 30분 안에 하루 한 번만 보냅니다.
- 로그아웃하면 그 기기의 알림도 꺼집니다. 앱을 지우거나 권한을 끈 기기는 다음 발송 때 서버에서 정리됩니다.
- "다시 찾아오는 감사" 알림은 일기 한 줄을 담아 보냅니다. 내용은 암호화되어 애플이나 구글의 푸시 서버를 거쳐 전달됩니다.

## 개발

빌드 과정 없이 정적 파일로 동작합니다. `python3 -m http.server`로 띄운 뒤 `http://localhost:8000`을 열어 확인하세요.

- `index.html`, `style.css`, `app.js`: 화면과 일기 로직
- `sync.js`: Supabase 인증과 동기화 (REST API 직접 호출, 외부 라이브러리 없음)
- `push.js`: 알림 설정과 이 기기의 푸시 구독
- `config.js`: 동기화 서버 주소와 키, 푸시 공개키
- `sw.js`, `manifest.webmanifest`, `icons/`: 설치, 오프라인 지원, 알림 표시
- `supabase/schema.sql`: 서버 표, 최신 수정 우선 규칙, 접근 권한
- `supabase/functions/send-reminders/`: 알림 보내기 (Deno, Supabase Edge Function)
- `supabase/cron.sql`: 알림 함수를 5분마다 실행
