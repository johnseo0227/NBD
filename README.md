# NBD — 감사 일기

매일 감사한 일을 기록하는 웹앱(PWA)입니다. 아이폰과 윈도우에 앱처럼 설치할 수 있고, 설치 후에는 인터넷 없이도 열립니다.

## 설치

앱을 HTTPS 주소에 올린 뒤(예: GitHub Pages, Netlify, Cloudflare Pages) 각 기기에서 엽니다.

- **아이폰**: Safari로 열기 → 공유 버튼 → "홈 화면에 추가"
- **윈도우**: Edge나 Chrome으로 열기 → 주소창 오른쪽의 "앱 설치" 아이콘(또는 메뉴 → 앱 → 이 사이트를 앱으로 설치)

로컬에서 확인할 때는 `python3 -m http.server`로 띄우고 `http://localhost:8000`을 엽니다. `index.html`을 파일로 직접 열어도 동작하지만, 그 경우 오프라인 기능과 설치는 되지 않습니다.

## 기능

- **오늘**: 감사한 일 3가지(무엇이 / 왜), 쓰기 전·후 기분, 나에게 고마운 점을 씁니다. 자동 저장됩니다.
  - 생각이 나지 않을 때 쓸 질문을 보여 줍니다.
  - 예전에 쓴 것과 비슷한 내용을 쓰면 알려 줍니다.
  - 어제 기록을 빠뜨렸다면 "이틀 연속으로 빠지지 않기"를 안내합니다.
- **기록**: 지난 일기를 검색하고, ⭐한 항목만 모아 봅니다.
- **회고**: 주간 통계(쓴 날, 감사한 것 수, 평균 기분 변화), 자주 나온 단어, 주간 회고 메모를 제공합니다.
- **설정**: 하루 항목 수를 바꾸고, JSON으로 내보내거나 가져옵니다.

데이터는 각 기기의 브라우저 `localStorage`에만 저장되며, 아이폰과 윈도우 사이에 자동으로 동기화되지 않습니다. 설정 → 내보내기/가져오기로 옮기거나 백업하세요.
